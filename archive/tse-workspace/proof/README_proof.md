# Archived TSE-era Rocq snapshot

These proof sources and their assumptions report are retained with the former
TSE-format working manuscript for historical reproducibility. They are not the
canonical source snapshot for the current IEEE Access article.

Use the current Rocq modules and audit in ../../../ieee_access/proof/, or the
matching frozen copy in ../../../release/ieee-access-paper1-submission-v3/proof/.
Run the current reproduction procedure from the ieee_access directory with
reproduce-ieee-access.ps1. The archival reproduce-tse.ps1 uses only this
historical proof directory and the files grouped with the TSE manuscript.
